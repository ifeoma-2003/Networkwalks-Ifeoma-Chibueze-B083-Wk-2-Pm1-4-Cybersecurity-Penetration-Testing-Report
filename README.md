## Penetration Testing & Reconnaissance

## Networkwalks Cybersecurity Internship-Week2

## Overview
Week 2 of the Networkwalks Cybersecurity Internship focused on the foundational reconnaissance activities performed during a penetration testing engagement.
The practical sessions provided hands-on exposure to techniques used to identify, collect, and analyze information about a target before proceeding to deeper security assessment.
The exercise emphasized the importance of reconnaissance as an initial phase of penetration testing. Through practical interaction with information gathering and network scanning tools
,i developed a better understanding of how publicly available information and network level data can contribute to the identification of potential attack surfaces.

The week's practical activities covered Footprinting, Google Hacking Database(GHDB), TheHarvester, and Zenmap/Nmap network scanning.

## Practical Modules

## PM1-Footprinting

Footprinting involved the systematic collection of information about a target from available sources. The exercise introduced the concept of reconnaissance and demonstrated
how information gathered during this phase can contribute to understanding a target's digital presence.
The practical emphasized the importance of observing available information before attempting any further security testing. It also provided an opportunity to understand how 
seemingly unrelated pieces of information can contribute to a broader picture of a target's online footprint.

## Key Focus Areas:
```
1) Information gathering
2) Target identification
3) Reconnaissance methodology
4) Identification of publicly available information
5) Understanding the importance of an organization's digital footprint

```
## PM2-GHDB/Google Hacking DataBase

The Google Hacking Database (GHDB) practical introduced the use of advanced search techniques to identify information that has been indexed and made discoverable through 
search engines.
Using carefully constructed search queries, the exercise demonstrated how search engines can serve as reconnaissance resources during a security assessment. It also high-
lighted the security implications of unintentionally exposed information and the importance of understanding what an organization makes publicly accessible.
This practical strengthened my understanding of how search operators can be applied during reconnaissance and why information exposure should be considered as part of an 
organization's overall security posture.

## Key Focus Areas:
```
1) Google search operators
2) GHDB
3) Search engine reconnaissance
4) Information exposure
5) Identification of publicly indexed resources

```
## PM4-TheHarvester

TheHarvester practical focused on automated information gathering through publicly available sources. The tool was used to demonstrate how security professionals can collect
reconnaissance data associated with a target during the early stages of an assessment.
The exercise provided practical exposure to the concept of Open-Source Intelligence (OSINT) and demonstrated how information from multiple publicly accessible sources can be
consolidated to provide a broader understanding of a target's digital presence.
This activity further reinforced the importance of reconnaissance in identifying information that may contribute to an understanding of a target's externally visible attack
surface.

## Key Focus Areas:
```
1) Open-Source Intelligence (OSINT)
2) Domain reconnaissance
3) Email and subdomain discovery
4) Public information gathering
5) Automated reconnaissance

```
## PM5-Zenmap/Network Scanning

The Zenmap practical introduced graphical network scanning and provided hands-on experience with identifying active hosts and examining network information.
Using Zenmap, the exercise involved observing hosts responding within a network and interpreting scan results. This provided a practical understanding of how network scanning
can assist in identifying systems that are reachable and potentially relevant to subsequent security assessment activities.
The practical also reinforced the relationship between reconnaissance and network visibility: before accessing the security of a network, it is important to establish an 
understanding of the systems and services that are visible within the environment.

## Key Focus Areas:
```
1) Network discovery
2) Host identification
3) Port scanning
4) Service enumeration
5) Interpretation of Nmap/Zenmap scan results

```
## Tools & Technologies

The following tools and technologies were utilized throughout the week's practical activites:
```
1) Kali Linux: Security focused Linux distribution used as the primary practical environment.
2) Google Hacking Database: Used for search engine reconnaissance and identification of publicly indexed resources.
3) TheHarvester: Used for automated Open-Source Intelligence and reconnaissance.
4) Zenmap: Graphical interface for network scanning and visualization.
5) Nmap: Network discovery and security auditing tool underlying Zenmap's scanning functionality.

```
## Competencies Developed

The Week 2 practical sessions significantly strengthened my understanding of reconnaissance as a structured component of penetration testing.
Through the exercises, i learned the following:
```
1) Reconnaissance establishes context before technical testing begins:
Understanding a target's publicly visible information and network presence provides a foundation for
subsequent security assessment activities.

2) Information exposure can contribute to an organization's attack surface:
Information that appears harmless in isolation may become more significant when combined with other publicly available data.

3) Search engines can be valuable reconnaissance resources:
Google Hacking Database demonstrated how advanced search operators can be used to locate resources that have been indexed by search engines.

4) Open-Source Intelligence can support structured information gathering:
TheHarvester demonstrated how publicly available information can be collected and organized to improve visibility into a target's external presence.

5) Network scanning provides visibility into reachable systems:
Zenmap/Nmap demonstrated how network scanning can identify active hosts and provide information relevant to network assessment.

6) Ethical authorization is fundamental to cybersecurity practice:
Information gathering and network scanning should be performed only within an authorized testing scope.

```
## Ethical & Professional Principle

The practical activities documented in this repository were undertaken for cybersecurity education and training purposes.
Reconnaissance and scanning techniques can provide valuable security insights when applied within an authorized environment. However, the same techniques can become
inappropriate when directed at systems, networks, or information without permission.
